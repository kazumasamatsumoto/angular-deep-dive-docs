# テンプレートと DOM

> 制御フロー・投影・i18n から DOM 操作まで

@for の差分、コンテンツ投影、@defer、ViewContainerRef、i18n、サニタイズ、そして最後に DOM へどう書き込まれるか。テンプレートが JS になるまでのコンパイラの段は「テンプレートコンパイラの内側」シリーズにまとめました。

全 8 章 · [サイトで読む](https://angular-deep-dive-cyan.vercel.app/series/template)

1. [track は何に使われているのか](01-for-track.md)  
   @for の差分アルゴリズムを読む。両端から詰める走査と、入れ替えを 1 回の操作で済ませる判定。track を書き間違えたときに何が起きるかが分かる。
2. [ng-content のセレクタは CSS ではない](02-projection.md)  
   コンテンツ投影の振り分けを読む。\* が最後に評価される理由と、対応しているセレクタがタグ名・属性・クラスだけである理由が分かる。
3. [@defer の中身は状態機械](03-defer.md)  
   8 種類のトリガーと 4 つの状態。on hover に focusin が入っている理由や、スピナーのちらつきを防ぐ 2 つの時間指定を読む。
4. [あとからビューを差し込む場所](04-view-container.md)  
   ViewContainerRef を読む。LContainer もまた先頭に固定の枠を持つ配列で、insert はすでに刺さっているビューを黙って外してから挿す。
5. [DOM を実際に出し入れする層](05-dom.md)  
   すべての章の終着点。Angular は document を直接触らず renderer を経由する。挿入の難しさは「どこに」を決める部分にあった。
6. [数値 1 つに 3 つの情報を詰める](06-i18n.md)  
   多言語化の命令はビットで詰められている。ソースに描かれたビットの地図を読み、変更マスクで変わった式だけを塗り直す仕組みまで追う。
7. [innerHTML のタグが消える理由](07-sanitize.md)  
   サニタイズの許可リストと URL 判定の正規表現を読む。何が残り何が消えるかは全部コードに書いてある。core に置かれた経緯も面白い。
8. [| async が面倒をみている 3 つのこと](08-async-pipe.md)  
   購読・解除・変更検知。毎回新しい Observable を渡すと購読し直しになる理由と、同期的な値では通知しない工夫を読む。
